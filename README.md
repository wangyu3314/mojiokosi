# Stream Subtitle App - Frontend (編集画面)

動画アップロード → 文字起こし結果の確認・編集 → 話者ごとの色分け、までができる画面です。
(動画への焼き込み・書き出しは次のステップで実装します)

## セットアップ

バックエンド(`stream-subtitle-backend`)を先に起動しておいてください
(`http://localhost:8000` で動いている状態)。

```bash
cd stream-subtitle-frontend
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 使い方

1. 動画ファイルを選択し、「アップロードして文字起こしを開始」をクリック
2. 少し待つと、文字起こし結果が行ごとに表示される
3. 右上の「話者を登録」で、名前を入力して話者を追加(色は自動で割り当てられる)
4. 各行のテキストを直接クリックして修正できる
5. 各行の右側のプルダウンで、その行の話者を選択する
6. 動画を再生すると、再生位置に対応する行がハイライトされる

「動画を書き出す」ボタンは現時点では準備中です。ffmpegでの焼き込み処理を
バックエンドに追加してから有効化します。
